# Тестування та забезпечення якості програмних систем

ПІБ: **Галух Анна Олександрівна**.  
Група: **63М**.

## Обраний застосунок
Навчальна «Система управління студентами»: REST API і вебінтерфейс для обліку студентів, виставлення балів, визначення ECTS та формування відомостей. Ролі: адміністратор, викладач, студент.

Попередній стек: Python, FastAPI, SQLAlchemy, PostgreSQL; вебінтерфейс React + TypeScript; pytest для модульних та інтеграційних тестів, Playwright для UI, k6 для навантаження. Це вибір для наступних робіт; реалізація застосунку до лабораторної № 1 не входить.

## Статус і межі роботи
Підготовлено документи та специфікації приймання. Сценарії описують очікувану поведінку, а не результати виконаних тестів. Step definitions і застосунок ще не реалізовано. Числові пороги та бізнес-правила, відсутні у вихідному завданні, є навчальними пропозиціями A-01…A-08 у рецензії, а не погодженими вимогами замовника.

## Використання ШІ
Використано OpenAI Codex для аналізу наданих PDF, підготовки рецензії вимог, пропозицій метрик, реєстру ризиків, сценаріїв Gherkin і перевірки зв'язків між документами. Матеріал підготовлено за допомогою ШІ; студент має перевірити рішення та вміти самостійно пояснити їх на захисті.

## Джерела
- Надана «Лабораторна робота № 1. Аналіз вимог і ризиків навчального вебзастосунку», розділи 1–6.

Модель ISO/IEC 25010:2023 застосовано за викладом у лекції; повний текст стандарту окремо не опрацьовано.
