## Використання ШІ

OpenAI Codex допоміг проаналізувати навчальний код, зібрати локальні докази, підготувати чернетку коментарів і пояснення перевірок. Рецензію потрібно перевірити самостійно: ШІ не виявив автоматично всі проблеми. Зокрема, зіставлення ECTS і форматів експорту з ЛР 1 та питання, який запис оцінки є чинним, потребували аналізу вимог. Зауваження про змінюваний аргумент `exclude` не доводить фактичного псування даних, бо список у функції не змінюється; це ризик майбутньої модифікації.
