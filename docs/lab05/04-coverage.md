# ЛР 5. Покриття коду та контрольна точка CI

Галух Анна Олександрівна, 63М. Запуск з `app/`: `uv run pytest --cov --cov-report=term-missing --cov-report=html -rxX`. [Повний протокол](evidence/coverage-full.txt) і [окрема перевірка Р-21](evidence/coverage-retake.txt) збережені поруч зі звітом.

## Результат

- 96 тестових випадків: **80 passed, 16 xfailed, 0 XPASS**. Відомі розходження пов'язані з issue #12–18 та #21–23; `xfail(strict=True)` сигналізуватиме про несподіване виправлення.
- Загальне покриття з урахуванням переходів: **88,71 %**, поріг **85 %** виконано.
- `retake.py`: **9 операторів, 4 переходи, 100 % покриття переходів**; окремий поріг **100 %** виконано.
- Для кожного PR і push до `main` завдання `tests` запускає обидва пороги й додає HTML-звіт `htmlcov` до артефактів. Артефакт створюється також після падіння перевірки, якщо HTML-звіт встиг сформуватися.

## Непокритий код

|---|---|---|---|

`cli.py` та `dean.py` виключено з модульного покриття за шаблоном ЛР: вони взаємодіють з консоллю і файловою системою, тому їх доцільніше перевіряти інтеграційними сценаріями. Виняток із вимірювання не означає, що ці інтерфейси вже перевірено; без системних тестів там лишається ризик.

Колонка `BrPart` показує частково перевірені розгалуження: хоча рядок було виконано, не всі виходи з умови виконувалися. Відсоток сам по собі не доводить правильність тверджень; для Р-21 кожен перехід поєднано з конкретним очікуваним результатом.

## Перевірка блокування злиття

Тимчасовий PR із вимкненим тестом `NoRetakeDateError` та його результат буде додано після запуску в GitHub. Цю гілку не зливати.
