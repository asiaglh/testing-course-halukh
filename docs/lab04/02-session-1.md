# Сесія ХС-01 — CSV-імпорт

- **Хартія:** Дослідити імпорт студентів із CSV через консоль деканату за допомогою файлів із BOM, пробілами, дублями email і помилкою в пізньому рядку, щоб виявити спотворення даних та порушення атомарності.
- **Авторка звіту:** Галух Анна Олександрівна, 63М. Перевірки виконано автоматизованими прогонами в ізольованих копіях даних; дослівні результати збережено нижче.
- **Початок:** 08.11.2026 17:15:44 (Europe/Kyiv). **Версія:** app-lab04 (0.4.0), macOS arm64, Python 3.14.10.
- **Межі сесії:** лише Р-19 через консоль деканату; кожен прогін має свіжу тимчасову копію `app/data/group.json`. В оригінальний файл нічого не записується.

## Ідеї для атак до прогону

1. Валідний приклад; порожні рядки; пробіли навколо полів; регістр назви фінансування.
2. UTF-8 з BOM; інший роздільник; пошкоджені байти; лапки та `;` усередині прізвища.
3. Дубль email усередині CSV і з уже наявним студентом, у тому числі з іншим регістром чи пробілами.
4. Помилка в першому, середньому та останньому рядку — чи залишається група незмінною.
5. Неповні поля, рядок тільки з пробілами, порожній файл і повторний імпорт.
